1. ##**What is Claude Code?**
- Claude Code **不依赖语义索引**，而是通过少量基础工具自主探索代码库：
    - 列出目录（`ls`）
    - 读取文件（`cat`）
    - 正则搜索（`grep`）
- 它会将探索过程中发现的关键信息记录在 `code.md` 文件中，作为后续决策的“笔记”

![[Pasted image 20260328232037.png]]
- **架构特点**
    - 本地运行，代码库无需上传或建立索引，安全性高。
    - 自主性来源于它能反复调用这些工具并“思考”下一步行动。、
**示例流程**
    1. 用户提出任务（如“添加登录功能”）
        
    2. Claude Code 先扫描项目结构，阅读相关文件
        
    3. 在 `code.md` 中记录发现
        
    4. 根据笔记制定计划并执行
