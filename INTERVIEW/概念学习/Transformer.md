### 2. 计算神经网络的参数（如何计算w和b？）
判断拟合效果：损失函数
![[Pasted image 20260407170416.png|587]]
![[Pasted image 20260407170610.png|590]]
（机器学习中最基本的方法）线性回归：通过寻找一个线性函数来拟合x和y的关系
![[Pasted image 20260407171200.png]]
梯度：让w和b不断往偏导数的反方向去变化，再增加一个==学习率==的系数来控制。这些偏导数所构成的向量就叫梯度。
梯度下降：不断变化w和b，让损失函数逐渐减小的过程，进而求出最终的w和b，这个过程就叫梯度下降。


反向传播（计算损失函数关于每个参数的梯度，然后每个参数都向着梯度的反方向变化），可以理解为复合函数求导（通过链式法则求导并逐层更新参数）
![[Pasted image 20260407171552.png]]
一次训练：一次前向传播、一次正向传播
![[Pasted image 20260407171733.png]]
### 3. 调教神经网络的方法
过拟合：在训练数据上表现很完美，但是对没见过的数据预测方面表现很糟糕的现象
泛化能力：在没见过的数据上表现能力
![[Pasted image 20260407172314.png|672]]
从训练数据上解决过拟合：增加数据量、![[Pasted image 20260407172548.png|363]]
从训练模型上解决过拟合：数据增强：在原有数据中创造更多数据（图象处理中对图像进行旋转、反转、裁剪、加噪声等操作）
![[Pasted image 20260407172709.png|384]]
从训练过程入手：不断调整参数（例如提前终止训练过程）
![[Pasted image 20260407185155.png|513]]
为了在训练中抑制参数的野蛮生长，我们可以在原有损失函数基础上再加上参数本身，从而使得每当参数改变时，参数和损失函数的总和必须要减小。
惩罚项：加入的参数本身，既可以是参数改变的绝对值求和（L1），也可以平方求和(L2)。
正则化：通过这种向损失函数中添加权重惩罚项抑制参数野蛮增长的方法叫做正则化。
正则化系数：类似于学习率，控制参数的参数统一称为超参数
![[Pasted image 20260407190040.png]]
 另一种方法Dropout：训练过程中，每次都随机丢弃一部分参数，让影响力大的参数偶尔缺席，这样模型就必须学会依赖更多普通参数，从而避免在某些关键参数上过度依赖的风险
 ![[Pasted image 20260407190142.png]]
其他问题：
![[Pasted image 20260407190405.png]]
梯度消失：网络越深，梯度反向传播时会越来越小，导致参数更新困难
梯度爆炸：梯度数值越来越大，参数的调整幅度失去了控制
收敛速度过慢：比如可能陷入局部最优或者来回震荡
计算开销太大：数据规模量太大了，每次完整的前向和反向传播都非常耗时。
### 4. 从矩阵到CNN
![[Pasted image 20260407190840.png]]
多个自变量和因变量时，可以利用矩阵乘法来表达复杂的神经元结构（利用GPU的并行计算优势，加速神经网络的训练和推理）![[Pasted image 20260407190931.png]]
如果有多层结构，可以采用符号化的表示（每一层神经元的值都是上一层的函数）
![[Pasted image 20260407191044.png]]
全连接层：每个神经元都与前一层的所有神经元相连
如果全用全连接层，会导致参数量巨大
![[Pasted image 20260407235609.png|511]]
![[Pasted image 20260408000906.png|535]]
在某一图像中，用一个已知的固定数值（灰度值）的3x3矩阵（卷积核）来遍历地扫过整个图像进行卷积运算，就可以对图像进行不同处理操作（如模糊、浮雕、轮廓等效果）
[Image Kernels explained visually (setosa.io)](https://setosa.io/ev/image-kernels/)
在深度学习领域，卷积核的值则是位置的，和其他变量一样，需要被训练出来。
据此，我们在神经网络中引入卷积层，也就是将原来的乘法计算转换为卷积计算
![[Pasted image 20260408001250.png|410]]
池化层：对卷积层后的特征图像进行降维，减少后续的计算量但是保留主要特征
![[Pasted image 20260408001442.png]]
卷积神经网络CNN(主要用于静态数据，对时间序列、文本、语音等则需要RNN)
